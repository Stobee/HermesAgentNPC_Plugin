Hermes Agent NPC UE5 Client

언리얼 엔진 5.8 C++ 기반으로 구축된 Hermes AI Agent NPC 클라이언트입니다. 소켓 기반 TCP 통신, 백그라운드 워커 Thread 안전 처리, 턴제/비동기 NPC 액션 디스패치 및 대화 UMG UI를 완전하게 통합 구현하였습니다.

01

프로젝트 개요

💡 구현 목적
외부 Hermes AI 서버(192.168.0.111:8770)와 통신하여 플레이어와의 자유형 텍스트 대화를 처리하고, 서버의 명령(이동, 추적, 인벤토리 관리, 아이템 주고받기)을 게임 내 NPC 동작으로 실행하는 비서 NPC 클라이언트를 제공합니다.
🛡️ 주요 특징
  • 4바이트 Big-Endian 프리픽스 프레이밍 (최대 1MB 바디)
  • 메인 스레드 락 없는 FRunnable 백그라운드 소켓 워커
  • SaveGame 기반의 고유 Player ID 유지 및 자동 재연결
  • 화이트리스트 기반 안전한 액션 핸들러 디스패치 (15초 타임아웃)
02

3계층 아키텍처 설계

언리얼 엔진의 렌더링/게임스레드 지연을 방지하고 네트워크 통신을 독립적으로 유지하기 위해 엄격한 3계층 아키텍처로 분리되었습니다.

1. Transport Layer
FHermesFrameCodec, FFrameAccumulator, FHermesSocketWorker로 구성되며 순수 바이트 스트림 파싱 및 백그라운드 TQueue 기반 스레드 안전 송수신을 담당합니다.
2. Connection Layer
UHermesConnectionSubsystem이 UGameInstanceSubsystem으로 동작하여 연결 수명주기, SaveGame UUID 영구 저장, identify 핸드셰이크 및 타임아웃/재연결을 총괄합니다.
3. Dispatch & Gameplay Layer
UHermesActionDispatcher가 액션 요청을 검증하고 4종의 IHermesActionHandler (MoveTo, Follow, Inventory, Transfer) 및 UMG 대화 위젯으로 라우팅합니다.
03

TCP 소켓 프레이밍 규약

프레이밍 구조: 모든 네트워크 패킷은 [4바이트 Big-Endian Length Prefix] + [UTF-8 JSON Body] 구조를 따릅니다. (최대 바디 크기: 1,048,576 Bytes / 1 MiB) 
+----------------------------------+-----------------------------------------------+
| Length Prefix (4 Bytes uint32)   | JSON Message Payload (UTF-8 Encoded String)  |
| Big-Endian Order                 | Max Length: 1,048,576 Bytes                   |
+----------------------------------+-----------------------------------------------+
04

JSON 메시지 타입 스펙

Message Type Direction 설명 및 주요 필드
identify Client → Server 클라이언트 식별 통지. player_id(UUID string), session_id(optional)
identified Server → Client 핸드셰이크 승인 응답. player_id, status:"ok"
chat Client → Server 유저 메시지 송신. id(c-0001), text
chat_response Server → Client AI 응답 대화 텍스트. id, text
action_request Server → Client NPC 행동 지시. id, command, params(JSON object)
action_result Client → Server 행동 실행 결과 회신(15초 내). id, ok(bool), result, error
ping / pong Bi-directional 연결 유지 헬스체크 핑퐁. id
05

화이트리스트 액션 규약

📍 1. move_to
지정한 월드 좌표로 NPC를 이동시킵니다. 
// params payload
{
  "location": { "x": 100.0, "y": 250.0, "z": 0.0 }
}
// result: { "arrived": true }
🚶 2. follow_player
플레이어를 150cm 거리에서 지속 추적하거나 정지합니다. 
// params payload
{
  "enabled": true
}
// result: { "following": true }
🎒 3. inventory_manage
NPC의 인벤토리 목록을 조회하거나 아이템을 드랍합니다. 
// params: { "operation": "list" }
// result: { "items": [{"item_id":"potion","quantity":5}] }
// params: { "operation": "drop", "target": "potion" }
🔄 4. item_transfer
플레이어와 NPC 간 아이템을 양도/수령합니다. 
// params payload
{
  "direction": "give", // or "receive"
  "item_id": "gold",
  "quantity": 100
}
// result: { "transferred": 100 }

07

언리얼 에디터 셋업 & 블루프린트 배선 가이드

🖥️ 1. UMG 대화 위젯 생성 (WBP_HermesDialogue)
  1. 에디터에서 UserWidget 기반 블루프린트 WBP_HermesDialogue를 생성하고 부모 클래스를 UHermesDialogueWidget으로 설정합니다.
  2. 위젯 디자이너에서 아래 3개 컴포넌트의 이름을 정확히 일치시켜 배치합니다.
    • InputBox (EditableTextBox): 유저 채팅 텍스트 입력창
    • DialogueText (TextBlock): NPC 대화 응답 및 상태 표시창
    • SendButton (Button): 전송 버튼
🤖 2. NPC 캐릭터 엑터 배치
  1. AHermesNPCCharacter 기반 블루프린트 BP_HermesNPC를 생성합니다.
  2. 디테일 패널의 Hermes -> Dialogue Widget Class 항목에 위에서 만든 WBP_HermesDialogue를 지정합니다.
  3. 레벨에 BP_HermesNPC를 배치하면 BeginPlay() 시 자동으로 UHermesConnectionSubsystem::RegisterNpc가 호출되어 액션 핸들러 4종이 배선됩니다.
🗺️ 3. 길찾기(NavMesh) 및 상호작용 입력
  1. NPC의 move_to 및 follow_player 동작을 위해 레벨 바닥에 NavMeshBoundsVolume을 설치합니다.
  2. 플레이어 캐릭터에서 NPC 근처 접근 후 키 입력(예: E키) 시 NPC의 Interact() 메서드를 호출하면 대화 위젯이 뷰포트에 열립니다.

실서버 연동 통합 체크리스트

  • 서버 192.168.0.111:8770가 켜진 상태에서 PIE 실행 시 identify 자동 수신 및 identified 연결 성공 확인
  • Saved/SaveGames/HermesPlayer.sav 파일에 영구 Player UUID 생성 확인
  • NPC Interact() 호출 시 대화창 표시 및 "생각 중..." 애니메이션 연동
  • 서버의 move_to, follow_player, inventory_manage, item_transfer 명령 시 15초 이내 action_result 회신 확인
  • 서버 오프라인 시 지수 백오프 자동 재연결 및 재접속 시 동일 UUID 재인증 확인
