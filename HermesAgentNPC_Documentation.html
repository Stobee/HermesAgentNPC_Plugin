Hermes Agent NPC UE5 Plugin Specification

언리얼 엔진 5.8 C++ 모듈과 완제품 블루프린트 에셋이 독립 패키지(Plugins/HermesAgentNPC/)로 결합된 AI Agent NPC 전용 플러그인 사양서입니다. 프로젝트 설정(UHermesSettings)을 통한 호스트/포트 제어 및 강력한 파라미터 안전 검증 기능을 내장하고 있습니다.

01

프로젝트 개요

💡 구현 목적
외부 Hermes AI 백엔드 서버(설정 기반 호스트/포트)와 통신하여 플레이어와의 자유형 대화 및 4종의 화이트리스트 인게임 액션 지시(이동, 추적, 인벤토리, 아이템 주고받기)를 비동기로 구동하는 완전 독립형 플러그인을 제공합니다.
🛡️ 핵심 경쟁력
  • 독립형 Plugins/HermesAgentNPC/ 패키지로 다른 UE5 프로젝트에 즉시 이식 가능
  • 에디터 Project Settings 및 Config/DefaultGame.ini를 통한 서버 주소 외부 전역 설정화
  • 완제품 블루프린트(BP_HermesNPC, WBP_HermesDialogue) 내장 (CanContainContent: true)
  • 파라미터 하드 바운드, 토큰 버킷 레이트 리미터, 큐 상한 제어로 악성 피어 방어
  • SaveGame 기반 영구 Player UUID 유지 및 15초 액션 타임아웃 디스패처
02

플러그인 패키지 디렉토리 구조

타 프로젝트 이식 시 ThirdPerson 템플릿 등 불필요한 의존성 없이, 오직 이 플러그인 폴더 하나만으로 모든 C++ 로직과 에셋이 동작합니다. 

Plugins/
└── HermesAgentNPC/
    ├── HermesAgentNPC.uplugin              <-- 플러그인 정의 매니페스트 ("CanContainContent": true)
    ├── Source/
    │   └── HermesAgentNPC/                 <-- C++ 시스템 전체 (18개 소스 및 헤더)
    │       ├── Actions/                    <-- 디스패처, 액션 핸들러 4종, 파라미터 검증, 레이트 리밋
    │       ├── Connection/                 <-- 연결 서브시스템, SaveGame, 보류 발화 상한

03

3계층 아키텍처 설계

1. Transport Layer
FHermesFrameCodec, FFrameAccumulator, FHermesSocketWorker로 구성되며 4바이트 길이 프리픽스 파싱, GetAddressInfo 기반 DNS 해석 및 TQueue 백그라운드 송수신을 담당합니다.
2. Connection Layer
UHermesConnectionSubsystem이 UGameInstanceSubsystem으로 동작하여 연결 수명주기, SaveGame UUID 영구 저장, identify 핸드셰이크 및 보류 발화 상한(PushBounded)을 처리합니다.
3. Dispatch & Gameplay Layer
UHermesActionDispatcher가 액션 파라미터를 하드 바운드로 검증하고, 토큰 버킷 레이트 리미터를 거쳐 4종의 IHermesActionHandler (MoveTo, Follow, Inventory, Transfer) 및 UMG 대화 위젯으로 라우팅합니다.
04

TCP 소켓 프레이밍 규약

프레이밍 구조: 모든 네트워크 패킷은 [4바이트 Big-Endian Length Prefix] + [UTF-8 JSON Body] 구조를 따릅니다. (최대 바디 크기: 1,048,576 Bytes / 1 MiB) 
+----------------------------------+-----------------------------------------------+
| Length Prefix (4 Bytes uint32)   | JSON Message Payload (UTF-8 Encoded String)  |
| Big-Endian Order                 | Max Length: 1,048,576 Bytes                   |
+----------------------------------+-----------------------------------------------+
05

JSON 메시지 타입 스펙

Message Type Direction 설명 및 주요 필드
identify Client → Server 클라이언트 식별 통지. player_id(UUID string), player_name(optional)
identified Server → Client 핸드셰이크 승인 응답. chat_id, ok:true
chat Client → Server 유저 발화 송신. id(c-0001), text
chat_response Server → Client AI 응답 대화 텍스트. id, text, actions
action_request Server → Client NPC 행동 지시. id, command, params(JSON object)
action_result Client → Server 행동 실행 결과 회신(15초 내). id, ok(bool), result, error
ping / pong Bi-directional 연결 유지 헬스체크 핑퐁. id
06

화이트리스트 액션 규약

📍 1. move_to
지정한 월드 좌표로 NPC를 이동시킵니다. 
// params payload
{ "location": { "x": 100.0, "y": 250.0, "z": 0.0 } }
// result: { "arrived": true }
🚶 2. follow_player
플레이어를 150cm 거리에서 지속 추적하거나 정지합니다. 
// params payload
{ "enabled": true }
// result: { "following": true }
🎒 3. inventory_manage
NPC의 인벤토리 목록을 조회하거나 아이템을 드랍합니다. 
// params: { "operation": "list" }
// result: { "items": [{"item_id":"potion","quantity":5}] }
🔄 4. item_transfer
플레이어와 NPC 간 아이템을 양도/수령합니다. 
// params payload
{ "direction": "give", "item_id": "gold", "quantity": 100 }
// result: { "transferred": 100 }
07

안전 검증 및 리소스 방어 (Safety Bounds)

서버로부터 수신된 악성 또는 비정상적인 액션 요청으로 인해 게임 로직이나 메모리가 오염되지 않도록 하드 바운드 검증 및 자원 제어가 이루어집니다.

검증 항목 하드 바운드 범위 위반 시 처리 및 회신 error
move_to 좌표 유한성 abs(v) <= 1e7 cm (MaxWorldCoordinate) 게임 로직 비실행, ok: false (coordinate out of range)
item_transfer.quantity 정수 범위 1 <= q <= 999999 게임 로직 비실행, ok: false (quantity out of range)
item_transfer.item_id 비어있지 않음 및 length <= 64 게임 로직 비실행, ok: false (invalid item_id)
액션 처리 속도 제어 토큰 버킷 레이트 리미터 (초당 최대 20회) 초과 액션 거부, ok: false (rate limited)
보류 발화 수 상한 PushBounded (MaxPendingChats=100) 미승인 세션에서 오버플로 시 가장 오래된 발화 자동 드랍
08

타 프로젝트 연동 (드래그 앤 드롭 가이드)

📂 1. 플러그인 폴더 복사
적용하고자 하는 UE 5.8 프로젝트의 루트 디렉토리에 Plugins/ 폴더를 만들고 Plugins/HermesAgentNPC/ 폴더 전체를 복사합니다.
⚙️ 2. .uproject 활성화 및 서버 주소 설정
대상 프로젝트의 .uproject 파일에 아래와 같이 플러그인을 활성화합니다. 
"Plugins": [
    { "Name": "HermesAgentNPC", "Enabled": true }
]
에디터의 Project Settings > Plugins > Hermes Agent NPC 또는 프로젝트의 Config/DefaultGame.ini에서 서버 호스트명과 포트를 설정합니다.
🎮 3. 레벨에 NPC 배치 및 사용
  1. 언리얼 에디터의 콘텐츠 브라우저 설정에서 "Show Plugin Content"를 체크합니다.
  2. HermesAgentNPC Content/NPC/BP_HermesNPC를 원하는 레벨에 드래그하여 배치합니다.
  3. 레벨 바닥에 NavMeshBoundsVolume을 배치하고, 플레이어 입력에서 BP_HermesNPC의 Interact() 메서드를 호출하면 즉시 대화가 구동됩니다.
